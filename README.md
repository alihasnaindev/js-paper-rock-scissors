# Paper, Rock, Scissors Game

Hey there! 👋 This is a classic **Paper,Rock, Scissors** game built using vanilla **JavaScript**, **HTML5**, and **CSS3**. 

I built this project to strengthen my understanding of core JavaScript concepts like DOM manipulation, event handling, conditional logic, and state management.

🚀 **Live Demo:** https://js-paper-rock-scissors.vercel.app/

---

## 🎮 How It Works

1. Pick your move:  **Paper**, **Rock**, or **Scissors**.
2. The computer randomly selects its move using JavaScript logic.
3. The game determines the winner based on classic rules and updates the score instantly on screen.
4. You can reset or play as many rounds as you like!

---

## ✨ Features

- **Interactive Gameplay:** Play directly against an AI computer opponent.
- **Real-time Score Tracking:** Keeps track of player wins, computer wins, and ties during the session.
- **Dynamic UI Updates:** Immediate visual feedback on win, loss, or draw using DOM updates.
- **Fully Responsive:** Clean layout that works smoothly on mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack & Concepts Applied

- **HTML5:** Structuring the game interface and elements.
- **CSS3:** Flexbox layout, buttons styling, and modern UI design.
- **JavaScript (ES6):**
  - Event Listeners (`addEventListener`)
  - Random choice generation (`Math.random()`)
  - Conditional statements (`if/else`) for game rules
  - Dynamic DOM updates for score and results
